This is barber and cosmetology booking telegram bot front end part, it was built using react.js and tailwind css with material ui component and models.
the models used here are the react.js new reliesed version, tailwinds last version and also the few component and libraries used, such as language change model with yandex maps api to locate nearest services and barbershops, and also it will show filtered services according to several filter options such as catalogs, nearest services and also cheapest or highly rated services within the selected city or area. One of best function of this programm is that you can book any service in advance and the bot will automatically remind you your appointment, the location of the service and other details like price, who will be your servicer and excetra. The front end part is highly reliable and optimized to be fast, efficient and beautifull due to it's optimized code, component libraries to be more responsive and tailwind and also some popular libraries to make it monotonous and beautifull
